SteamYard Deployment

Cloudflare Workers architecture and security model

Architecture: SteamYard runs on Cloudflare Workers, a serverless platform that executes code on the edge closest to users. The custom domain routes all requests through Cloudflare's global network, which handles TLS termination, DDoS protection, and geographic distribution.

Deployment environment

Platform: Cloudflare Workers (serverless edge computing)

Runtime: V8 JavaScript engine

https://steamyard-mcp.ackros.gg/mcp

Region: Global (Cloudflare edge network)

Secrets management

Three secrets are stored in Cloudflare KV (encrypted key-value store):

  • STEAM_API_KEY — Steam community API key
  • ITAD_API_KEY — IsThereAnyDeal API key
  • MCP_AUTH_TOKEN — Bearer token for /mcp endpoint auth
Secrets are NOT stored in git or .env files — they live only in Cloudflare's encrypted vault.

Build and deployment

Build tool: Wrangler (Cloudflare's CLI)

wrangler deploy

Source: Git repository at github.com/brwinnov/steamyard

CI/CD: Manual deployment via Wrangler CLI (no automatic pipeline)

Scaling and limits

Concurrency: Cloudflare Workers auto-scales horizontally

Timeout: 30 seconds per request (Cloudflare limit)

Request size: Max 100MB request body

Rate limits: No Cloudflare rate limit; controlled by external API quotas
