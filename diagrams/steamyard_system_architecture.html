SteamYard System Architecture

How components connect to deliver Steam game data queries

Overview: The SteamYard MCP server sits between Claude clients and three external APIs. Clients connect via the MCP protocol to query game ownership, DLC availability, pricing comparisons, and historical price trends. The server handles authentication, routing, caching, and retry logic before returning structured JSON responses.
Clients — Apps connecting to the MCP server
MCP Server — The SteamYard request handler and router
External APIs — Third-party services providing game data
Infrastructure — Hosting and deployment details
