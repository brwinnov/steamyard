SteamYard API Tools

The four query tools available via the MCP interface

Overview: SteamYard exposes four tools that clients can invoke. Each tool targets a specific data need and queries one or more external APIs. All results are cached to avoid redundant API calls and to respect rate limits.

get-owned-games

Returns a list of all Steam games owned by a given user. Requires a Steam user ID.

GET /api/IPlayerService/GetOwnedGames/v1/

get-game-dlc

Retrieves all DLC (downloadable content) available for a specific Steam game. Requires an app ID.

GET /api/appdetails

compare-dlc-prices

Compares a game's DLC prices across multiple storefronts using IsThereAnyDeal. Shows lowest price per DLC.

GET /api/v2/prices

price-history

Shows historical price trends for a game over time. Useful for spotting seasonal sales and pricing patterns.

GET /api/v2/prices/history
